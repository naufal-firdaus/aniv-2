Taruh foto-foto kalian di folder ini.

Cara pakai:
1. Copy foto ke folder ini, contoh: /public/images/foto1.jpg
2. Buka /lib/config.js
3. Di bagian `gallery`, ganti URL dengan path lokal:
   { src: "/images/foto1.jpg", caption: "Caption kamu" }

Tips:
- Resize foto ke maksimal 1600px lebar untuk loading cepat
- Format .jpg atau .webp untuk file kecil
- Bisa juga pakai layanan hosting gratis seperti Cloudinary atau Imgur
- Atau lewat URL Unsplash (sudah disetting di config default)
